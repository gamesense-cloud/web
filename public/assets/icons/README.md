# icons

Inline SVGs that are part of a component's markup (the bell and the envelope in
`Navbar.jsx`) live in the component, so they inherit `currentColor` and change
with hover and focus without a second request.

The files here are the ones referenced by URL — build status, thread state, and
anything a post body can point at. They are all single-path, `currentColor`
where it makes sense, and sized to a 16px box.
